# eddieshouse3

A first-person browser game prototype built with vanilla HTML, CSS, and canvas.

## Run locally

python3 -m http.server 8000

Then open http://localhost:8000

## Controls

- W/A/S/D: move
- Arrow left/right or mouse: look
- Click / E / tap: interact with the plant
- P: toggle debug overlay when debug mode is enabled

## Current prototype

Explore a shifting house with a living room, bedroom, changing hallway, ghost NPC, and plant growth mechanic.
